Admin Access

This area manages your memory content.

Memories — Admin

This is a static site (no server, no database), so this panel can't save changes back to your files automatically. What it can do: show you the current content, let you edit it in a friendly form, and generate the exact JSON/Markdown text to paste back into the matching file in content/. Think of it as a content co-pilot, not a live CMS.

Settings — Names, Dates, Location, Theme

All of these live in config/config.js. Edit that file directly — it's plain, commented JavaScript, safe to open in any text editor.

Password Hash Generator

Never store a plain-text password in config.js. Type a password below, copy the resulting hash into security.memoryPasswordHash or security.adminPasswordHash.

Security note: this admin panel and the memory password are meant to keep casual visitors out of a private page, not to protect against a determined attacker with access to your source code. Don't use it for anything more sensitive than a sentimental gift.
